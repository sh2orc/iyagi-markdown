# IYAGI Markdown

**Your Interface to AGI** — 마크다운으로 쓰고, 원문을 지킨다.

한국어 | **[English](README.md)** · [다운로드](#다운로드) · [릴리스 노트](RELEASE.md)

IYAGI Markdown은 `.md` 파일을 더블클릭하면 즉시 깔끔하게 렌더링해 보여 주고, 같은 창에서 바로
편집·저장할 수 있는 **경량 macOS 마크다운 리더/에디터**다. Tauri 2 + Rust + React/TS + CodeMirror 6.

- **원문 무손실**: 문서는 언제나 마크다운 텍스트 그대로다. 저장은 버퍼를 원자적으로 쓴다
  (임시 파일 → rename). BOM·CRLF/LF·마지막 개행이 보존되고, 수정하지 않은 문서는
  저장이 일어나지 않는다. HTML 변환을 거치는 편집 경로는 존재하지 않는다.
- **라이브 프리뷰(WYSIWYG)**: 제목·강조·링크·표·체크박스·이미지·수식(KaTeX)·다이어그램
  (mermaid)을 CodeMirror 6 장식·위젯으로 렌더한다. 인라인 마커(`**` 등)는 커서·선택
  끝점이 마크에 닿을 때만 원문이 드러난다 — ⌘A나 넓은 드래그로 선택해도 렌더링은
  그대로이고 선택 하이라이트만 얹힌다(Typora 방식), 위젯(표 셀·수식·다이어그램·
  프런트매터)은 클릭 한 번으로 해당 원문 위치를 편집한다. 제목은 `#`/`##`(ATX)로만
  만든다 — 밑줄형(Setext, `---`/`===`)은 제목이 아니게 타이핑 시점에 빈 줄로 분리되고
  (Word식), `---`은 수평선(구분선)이 된다. 분리를 못 한 외부 문서도 렌더는 문단+
  구분선으로 보이고, 내보내기에서도 같은 해석이 되도록 짝에 빈 줄을 넣어 정규화한다.
- **출력 불변**: 내보내기의 다이어그램·수식은 항상 대상 형식의 네이티브 벡터·편집 가능
  객체다. PDF는 벡터 경로, DOCX는 DrawingML 도형 그룹과 OMML 수식. 래스터화 없음.
- **가볍게**: 14MB(.app) · KaTeX·mermaid·highlight는 지연 로딩 청크 · 커서 이동당
  재계산 = 청크 1~2개(문서 크기와 무관).

## 빠른 시작

1. DMG를 열고 **IYAGI Markdown**을 응용 프로그램 폴더로 끌어넣는다.
2. `.md`/`.markdown` 파일을 더블클릭하면 렌더링된 채로 열린다. 파일 › 열기, Dock 아이콘에
   드롭, 시작 화면에서도 열 수 있다.
3. 기본이 라이브 프리뷰다. 읽기 모드 ⌘E, 소스 모드 ⌘/.
4. 모든 명령은 명령 팔레트 ⌘⇧P에 있다. 인쇄 미리보기 ⌘P, 폴더 검색 ⌘⇧F, 팔레트에서 빠른 열기.

## 왜 IYAGI인가

많은 마크다운 에디터가 `.md` 파일이 존재하는 이유 두 가지 — 원문과 출력 — 를 슬그머니
포기한다. IYAGI Markdown은 둘 다 지킨다:

- **디스크의 파일이 곧 문서다.** 데이터베이스도, 잠금도, HTML 왕복도 없다. 저장은 원자적
  (임시 파일 → rename)이고 바이트(BOM·줄바꿈·마지막 개행)가 보존되며, 수정하지 않은
  문서는 절대 쓰지 않는다.
- **보이는 것이 파일에 있는 것이다.** 라이브 프리뷰는 텍스트를 변환한 결과가 아니라
  텍스트 위의 뷰다 — 모든 렌더링은 디스크의 바이트에서 다시 만들 수 있다.
- **내보내기는 편집 가능하게.** 수식과 다이어그램은 대상 형식의 원생 객체(PDF 벡터 경로,
  DOCX OMML·DrawingML)로 나가지 래스터 그림으로 나가지 않는다.
- **가볍게.** 14MB 앱, 무거운 렌더러는 지연 로딩, 장식 갱신은 문서 10쪽이나
  500쪽이나 같은 비용.


## 기능

### 문서 편집
- 파일 연결(`.md`/`.markdown`) — 더블클릭·Dock 드롭·`open -a`·파일 › 열기
- 시작 화면 — 최근 문서·템플릿 바로가기(문서가 없을 때)
- 최근 작업 폴더 — 사이드바·시작 화면·명령 팔레트에서 다시 열기, 최대 20개 재시작 보존·창 간 동기화, 목록에서만 제거·비우기
- 템플릿 선택 — 시작 화면·명령 팔레트에서 검색, 미리보기·원문 확인 후 새 탭으로 생성. 한국어·영어 8종(프로젝트 계획·주간 계획·의사결정 기록 포함), 생성 시점의 로컬 날짜 반영
- 내 템플릿 — 현재 문서의 원문을 저장하거나 새로 작성, 이름·설명·본문 편집과 삭제, 다른 창의 동시 수정 보호·별도 사본 저장. 로컬에 최대 100개·각 512 KiB 보관하며 이미지 파일은 복사하지 않음
- 템플릿 백업·이동 — 선택한 사용자 템플릿을 JSON으로 내보내고 원문을 검토해 가져오기. 기존 항목을 덮어쓰지 않고 일괄 추가하며, 파일당 최대 64 MiB 지원
- GFM: 표(셀 제자리 편집(Word식 — 클릭해 바로 입력, Tab/Enter 셀 이동, Esc 취소)·헤더 클릭 정렬·열 폭 드래그·행/열 편집·자동 형식화·저장 시 정리 옵션), 작업 목록, 취소선, 각주
- 표 셀 사각 다중 선택 — 드래그·⇧클릭·화살표 이동·⇧화살표 확장 + Enter/⇧Enter 편집(↓·↑)·Esc 뒤 재시작·Delete 비우기·⌘C TSV 복사·표 전용 메뉴(우클릭·⇧F10) — 전 흐름 키보드 가능·활성 셀 뷰 추종
- 표 셀 병합 — 선택 영역을 한 셀로(`>` 왼쪽·`^` 위 마커, 앱 렌더 전용 — 다른 렌더러에서는 기호 텍스트로 강등)·병합 해제
- 서식 도구모음·선택 미니 바(B/I/S/코드/링크)·우클릭 컨텍스트 메뉴
- 목록 자동 계속(Enter)·Tab 들여쓰기·줄 이동(⌥↑↓)·복제(⌘D)·삭제(⌘⇧K)
- 멀티커서 편집 — ⌥클릭 커서 추가·⌥⌘↑↓ 위/아래 커서·⌥⌘D 다음 같은 단어 선택·⌥드래그 사각(열) 선택(Esc 해제)
- 줄 정렬(오름/내림)·중복 줄 제거 — 명령 팔레트·우클릭 메뉴(자연 숫자 정렬)
- `/` 메뉴(Notion식 블록 삽입) — 줄 처음(또는 공백 뒤) `/` 입력 시 제목·목록·표·코드·수식·이미지·링크·수평선·페이지 나누기·목차 등 삽입(한글·영어로 검색, Enter 적용)
- 이모지 자동완성 — `:기쁨`·`:coffee`의 한글 별칭·정확한 이름 우선 검색, 콜론 없이 문자만 삽입, 기존 닫는 콜론 처리와 한 번의 실행 취소
- 입력 보조: 괄호 쌍·마커 감싸기(`$`·`` ` ``·`*`·`~`)·강제 줄바꿈(⇧⏎)·페이지 나누기(⇧⌘↵ — Word 쪽나눔, `\newpage` 문단)
- 스마트 붙여넣기: HTML→마크다운 변환(Word/브라우저→IYAGI)·URL→링크·이미지 붙여넣기·TSV→표(엑셀·시트)
- 클립보드 편집 보호 — 이미지 이벤트 데이터 그대로 저장, 지연 붙여넣기의 문서·선택 범위 확인, 복사 성공 후에만 잘라내기
- 이미지 드롭·붙여넣기·파일 선택 — 문서 폴더 assets/로 복사, 입력 중 삽입 위치 보정, 여러 장을 한 번에 실행 취소, 부분 실패 표시(한 번에 32장·파일당 32 MiB)
- 그림 캡션 — `![설명](이미지)`의 대체 텍스트가 캡션으로
- 표 캡션 — 표 다음 `: 설명` 줄(Pandoc 규약), 내보내기에서 '표 N' 번호
- 문서 메모(주석) — 줄 앵커 사이드카·패널(편집·해결·삭제·클릭 이동), 원문 불변
- 메모 DOCX 내보내기 — Word 원생 메모(검토 창에서 그대로)
- 문서 검수 허브 — 끊긴 링크(원클릭 생성)·긴 문장·인용(끊긴 키 ⚠·서지로 이동)·고아 이미지(휴지통 이동 — Finder 복구 가능)를 한곳에서
- 제목·목록·코드펜스·인용 접기(거터 ▾) · 모두 접기/펼치기 · 시스템 맞춤법 검사(옵션)
- 코드펜스 언어 자동완성 — `py`·`js` 등 이름·별칭 검색, 긴 펜스와 목록·인용문 안 코드 블록 지원, 기존 언어 토큰 교체·메타데이터 보존, 코드 블록 안 키워드·지역 변수 제안
- 들여쓰기 가이드 — 중첩 목록 2공백 단위 세로 안내선(공백 폭 실측, 코드펜스 제외)
- 서식 복사(⌥⌘C/⌥⌘V) — 굵게·기울임·코드·취소·형광펜 서식을 평문에 붙여넣기. 제목 수준·인용 등 문단 서식도 함께 복사(본문 서식을 붙이면 제목 표시가 벗겨짐 — Word 서식 붓과 같은 교체 의미론)
- 도구모음 실행 취소/다시 실행·문단 정렬 — 명령 팔레트 단축키 칩(kbd) 표시
- 서식 없이 붙여넣기(⌥⌘⇧V) — 마크다운 변환 없이 순수 텍스트로
- 서식 복사: 마크다운 문법이 있는 선택을 복사하면 HTML도 클립보드에(Word/메일에 서식 유지)
- 자동 저장(옵션) — 탭·분할 편집 문서별로 입력을 모아 원자적으로 저장, 설정 해제 시 대기 중인 저장 취소
- 복구 초안 — 문서별로 미저장 내용을 보관하고, 원래 내용으로 되돌리거나 버린 초안이 재시작 때 다시 나타나지 않도록 정리

### 문서별 스타일(SQLite 사이드카 — 원문 불변)
- 폰트 4종(시스템/세리프/라운드/고정폭)·크기·행간·문단 간격·정렬(양쪽 포함)·들여쓰기·강조색
- 프리셋: 보고서·블로그·메모·논문·개발 노트
- 이미지 크기(개별)·표 열 폭(개별)·책갈피
- 편집기·HTML·PDF·DOCX 4경로에 동일 적용

### 노트 체계
- 위키링크 `[[이름]]` + 자동완성(`[[` 입력 시 목록) + 백링크 패널(🔗 N 클릭, 일반 Markdown 인라인·참조형 링크 포함)
- 노트 임베드 `![[이름]]` — 대상 문서 원문을 카드로 인라인(클릭 → 열기, 커서가 닿으면 원문). 내보내기 전 경로(HTML·PDF·EPUB·DOCX 공통)에서 깊이 4·순환 방지와 함께 실제 내용으로 풀어 넣음 — 읽을 수 없으면 원문 그대로
- 콜아웃 `> [!유형] 제목` — 인용문 첫 줄 마커로 카드 유형 13종(note·abstract·info·todo·tip·success·question·warning·failure·danger·bug·example·quote, 별칭 27종 정규화). 라이브 프리뷰 아이콘·유형색 카드, HTML/EPUB/PDF 카드 스타일, DOCX 유형색 채움 표 카드. 원문은 그냥 인용문이라 다른 렌더러에서 무해하게 강등
- 제목 이름 바꾸기(명령 팔레트) — 커서 제목의 텍스트를 고치고 이 제목을 가리키는 `[[문서#앵커]]`·`[[#앵커]]` 링크를 워크스페이스 전체에서 갱신(제목 표기·슬러그 표기 모두, 다른 파일은 디스크 기대값 비교로 안전 적용)
- 데일리 노트(명령 팔레트 '오늘 문서 열기') — 오늘 날짜(로컬) 문서를 열거나 없으면 만듦(루트 우선 탐색)
- 문서 링크의 `#제목` 위치로 이동 · 검색/백링크 결과 줄 이동 · 비동기 파일 열기 중 이후 탭 선택과 커서 위치 보존
- 문서 이동 기록 — 탭·링크·목차·책갈피 이동 전 위치로 뒤로/앞으로(⌥⌘←/→), 선택 범위·읽기 위치 복원과 편집 위치 보정, 열린 문서 대상 창별 기록
- 닫은 탭 다시 열기(⇧⌘T) — 탭 막대·파일 메뉴·명령 팔레트에서 창별 최근 20개 파일 복원. 최신 파일을 읽고 탭 순서·보기 모드·잠금·선택 위치를 복원하며, 폐기한 미저장 내용은 복원하지 않음
- 문서 그래프 — 위키·일반 Markdown 링크의 실제 문서 연결 시각화(노드 크기=연결 수·활성 문서 강조), 휠 줌(커서 고정)·드래그 팬·노드 더블클릭 열기·배경 더블클릭 리셋·키보드 탐색(←→↑↓ 이동·Enter 열기·+/−/0 줌), 250개 초과 문서는 원형 배치
- 링크 호버 미리보기(위키·내부 마크다운·각주 — 렌더 팝오버) · 현재 본문의 끊긴 로컬 링크 검사(실제 이미지·참조형 링크·확인 불가 구분)·누락 문서 생성 · 목차 삽입·그림/표 목차(lof/lot)·HTML/PDF 정적 목차(제목 앵커)·문서 정리(빈 줄 정규화+표 정렬)
- 태그 `#태그` + 자동완성(`#` 입력 시 목록) + 클릭 → 워크스페이스 검색
- 빠른 열기(명령 팔레트에서 파일 퍼지 검색)
- 폴더 전체 검색(⇧⌘F) — 누락 사유·읽은 파일 수·결과 제한 표시, 저장 변경 후 재조회 · 모두 바꾸기(변경 검토·백업·파일별 비교 저장·메타 보존)
- 버전 기록: 저장 직전 스냅숏 30개 + diff 미리보기 + 복원
- 메모(Word 메모): 줄 앵커 사이드카 — 우클릭 추가·호버·패널 검토·DOCX 원생 메모로 내보내기
- 문서 검수 허브: 끊긴 링크·긴 문장(점선 표시 토글)·고아 이미지 정리
- 파일 관리: 사이드바 우클릭 — 새 문서·이름 변경·복제 · 이름 변경 후 위키링크·Markdown 링크(인라인/참조형) 변경 미리보기·백업·비교 적용·검토 작업 재시작 복구
- 문서 비교(diff 뷰 — 다른 파일 또는 디스크 버전과)
- 하이라이트 `==텍스트==`(색 5종 선택) · YAML 프런트매터(문서 정보 편집 폼)
- 저장 파일명에 프런트매터 제목 반영 · 탭 우클릭 'Finder에서 보기'

### 탐색·도구
- 명령 팔레트(⌘⇧P) — 모든 명령 퍼지 검색 · `@` 문서 내 제목 점프 · 최근 명령 우선
- 목차(TOC) 패널 — ATX·밑줄형 제목 탐색, 스크롤 추적·현재 제목 강조, 원문 공백을 보존하는 루트 섹션 드래그 이동
- 목차 키보드 탐색 — 위아래·Home/End로 포커스 이동, 좌우로 접기·펼치기와 부모·자식 이동, 한글 조합형 검색·Enter로 제목 열기·Escape로 검색창 복귀
- 제목 링크 — 중복 제목과 자동 번호의 앵커 충돌 방지, HTML·DOCX에 같은 중복 할당 규칙 적용, DOCX 서식 제목·인코딩된 내부 링크 처리
- DOCX 제목 앵커 — 인용 변환 전 원문 기준으로 생성, 본문 제목을 먼저 배정하고 사용된 각주 제목은 참조 순서로 배정
- 분할 편집(참조 보기) — 옆에 고정한 문서를 바로 수정, 비례 동시 스크롤
- 변경 추적 — Word Track Changes의 마크다운 판: 삽입·삭제 표시·변경 내용 패널·상태 줄 ✎ +N −R·덩어리별 되돌리기('거부')·다음/이전 변경 탐색·삭제 블록 본문 표시(취소선)·클릭 ↺ 되돌리기
- 문서 통계(단어·글자·문단·표·읽기 시간·문장 길이 분포·긴 문장 클릭 이동) · 선택 통계('3단어 · 12자') · 할 일 진행률(☑ 3/7)
- 같은 단어 강조(커서 단어의 발생 — Word 표준) · 참조 보기(탭을 옆에 고정해 나란히)
- 긴 문장 표시(옵션) — 편집기에서 60자+ 점선 밑줄(작가 보조)
- 서식 기호 보기(설정·팔레트) — 공백 ·· 탭 → 줄끝 ¶(Word 서식 기호, 중복·끝공백 가시화)
- 인용·서지 — 본문 `[@key]` → [N] 위첨자(첫 등장 순)·서지 정의 `[@key]: 항목`(HTML 링크·번호 매김, 편집기 툴팁·끊긴 인용 표시) + `[@` 자동완성(서지 설명·기존 괄호와 페이지 표기 보존·후보 갱신)
- 인용·서지 DOCX — 인용이 서지 앵커 하이퍼링크(위첨자)·서지 문단이 북마크(Word에서 클릭 이동), 끊긴 인용은 원문 보존
- DOCX 인용 보호 — 코드·기존 링크·이미지·수식 안 표기 제외, 특수문자 접미사와 각주 인용 처리, 인접 서지 항목별 이동 대상 보존
- 인용 검수·프리뷰 — 공통 구문 분석으로 코드 예시·메타데이터 오탐 방지, HTML 중첩 인용 링크 방지와 이미지 설명 보존
- 상태 줄 브레드크럼 — 현재 제목 경로 표시·클릭 이동
- 키보드 단축키 도움말(도움말 › 키보드 단축키)
- 명령 팔레트 — 파일만 검색해도 Enter로 열기, 목록 갱신 중 선택 유지, 입력 포커스를 유지하는 방향키·Page Up/Down 탐색
- 대화상자 키보드 조작 — 열릴 때 포커스 이동, 겹친 창·진행 창 안 Tab 순환, 닫은 뒤 이전 버튼·입력 위치로 복귀
- 명령 처리 — 대화상자 입력 중 배경 문서 명령 차단, 입력창이 처리한 단축키 존중, 네이티브 메뉴의 버전 기록·폴더 검색·기호·링크 검사 연결 보완
- 문서 정보 편집 — 대상 문서·외부 정보 변경 확인, 초안 폐기 확인, 수정한 항목만 반영하며 본문·줄바꿈·다른 메타데이터 보존
- 링크·이미지 편집 — 대상 위치 추적과 변경 충돌 차단, 오류 시 초안 유지, 특수문자 처리와 기존 링크 제목·미수정 서식 보존
- 이미지 뷰어 — 중복 이미지의 원문 위치 구별, 코드·수식·메타데이터를 제외한 이전/다음 탐색, 설명 유지와 이미지별 확대·회전 초기화
- 표 삽입 — 원래 선택 위치 추적, 문서 전환·변경 충돌·적용 거절 시 입력 유지, 본문 행과 헤더를 구분한 미리보기, 여러 줄 선택 교체와 개별 실행 취소
- 기호 삽입 — 원래 선택 위치에서 연속 삽입, 검색창 포커스 유지, 검색어 편집과 결과 탐색 키 구분, 문서 전환·삽입 실패 안내
- 슬래시 명령 — 한·영 별칭 검색과 지우기 후 결과 복원, 코드·수식·링크 내부 제외, 목차·페이지 나누기 삽입의 원문 보존과 한 번의 실행 취소
- 위키·태그 자동완성 — 동명 문서의 실제 경로 구분, 특수 파일명의 Markdown 링크 대체, 기존 괄호·앵커·별칭 보존, 후보 복원과 중첩 폴더 변경 반영
- 문서 찾기·바꾸기 — 한글 단어 경계·정확한 유니코드 위치·정규식 캡처 치환, 예약 검색과 탭 전환 처리, 전체 건수 확인 후 바꾸기와 변경된 문서 보호
- 검색 응답성 — 정규식·큰 문서 검색을 백그라운드에서 계산, 변경·닫힘 시 취소, 시간 초과 안내와 재시도, 대기 중 커서 위치 보존
- 검색 결과 이동 — 표시 상한 밖의 결과도 다음·이전으로 탐색, 필요한 결과 구간만 유지하며 문서 전체 순번·총 건수와 끝에서의 순환 이동 지원
- 인쇄 미리보기(⌘P) — 용지·방향·여백·배율 반영, 준비 전 인쇄 방지·오류 재시도·키보드 탐색. 확인한 HTML을 PDF 생성에 재사용하며 내보내기 옵션은 재시작에도 유지
- 내보내기 취소·실패 후 창과 옵션 유지, 같은 문서로 재시도. 완료 시 실제 저장 경로·Finder에서 보기 제공, 처리 중 중복 실행·닫기 방지

### 출력
- HTML: 자체 완결형 단일 파일(이미지·폰트 인라인, DOMPurify)
- PDF: 벡터·용지·여백·배율·페이지 번호(N / M)
- DOCX: Word 기본 스타일 + 문서별 스타일 + OMML 수식 + DrawingML 도형 + 표 + 페이지 번호(옵션) + 페이지 나눔(`\newpage` → 쪽 나눔)
- HTML/PDF: `\newpage` 문단이 페이지 나눔으로(인쇄·PDF는 물론 화면에서도 점선 표시)
- 다단 레이아웃 — 프런트매터 `columns: 2`(·3): HTML·인쇄 CSS 다단(h1·h2는 단 관통), PDF 타일링이 단 폭 재계산, DOCX sectPr w:cols(Word Layout > Columns와 동일)
- 머리글/바닥글 자유 텍스트 — 프런트매터 `header:`·`footer:`: 머리글은 문서 제목 대신, 바닥글은 쪽번호와 함께(HTML·PDF·DOCX footer1.xml — Word 실행 머리글/바닥글)
- EPUB: EPUB 3 전자책(목차·챕터·표지·본문 이미지 임베딩), 최상위 제목 기준 분할과 장 사이 제목·각주 왕복 링크
- EPUB 저장 보호 — ZIP 완성 후 파일 교체, 누락 이미지·표지 오류 보고, 특수문자 경로와 참조형 표지 이미지 처리
- 내보내기 일관성 — 시작 시점의 본문·스타일·설정·메모를 함께 캡처하며 DOCX도 ZIP 완성 후 파일을 교체
- DOCX 메모 — 같은 줄의 여러 메모 보존, 제목·목록·표 행·코드 줄 연결, 각주 처리 이후 줄 위치 유지
- DOCX 각주 — 파서 기반 참조 처리, 여러 문단·목록·코드 보존, 각주 링크·그림 연결
- DOCX 그림 — 문단 뒤 독립 캡션, 목록·표 셀·각주 안 캡션 유지, SVG·Mermaid 그림 구조 보완
- DOCX 이미지 연결 — 그림 종류 간 ID 충돌 방지, 공백·특수문자 URL과 쿼리·조각 식별자가 붙은 로컬 이미지 처리
- DOCX 목록 — 시작 번호·목록별 재시작·중첩 번호·괄호 구분자 유지, 계속 문단의 번호 및 체크박스 중복 방지
- HTML·PDF·EPUB 참고문헌 — 강조·코드·링크·각주 서식, 인접 항목별 문단과 중첩 목록 안 이동 대상 유지

- 탭(드래그 순서·새 창 ⤢·잠금 🔒·세션 복원 — 참조 보기 고정·폴더 접힘 포함) · 폴더 사이드바(트리·파일 감시)
- 탭 키보드 조작 — 좌우·Home/End 탐색 후 Enter/Space 선택, Delete 닫기 확인, Shift+F10 메뉴·순서 변경, 닫힌 탭의 포커스 복귀 · 휠은 탭 목록 스크롤
- 사이드바 키보드 탐색 — 파일명 입력·반복 글자 순환, 한글 정규화 검색, 삭제된 행의 포커스 복구, 비활성 메뉴 항목 건너뛰기·메뉴 종료 후 원래 행 복귀
- 문서 즐겨찾기 — 파일·탭 메뉴에서 등록/해제, 사이드바·시작 화면·명령 팔레트에서 접근, 창 간 동기화·재시작 보존·이름 변경 추적
- 즐겨찾기 순서 편집 — 화살표 버튼·Option/Alt+↑·↓로 이동, 저장 후 위치 안내와 포커스 유지, 다른 창의 동시 변경 시 재확인
- 새 폴더 — 사이드바 루트 버튼·폴더 메뉴에서 생성, 이름 충돌·제외 이름 안내와 재시도, 생성 후 상위 폴더 펼치기·새 폴더로 이동
- 문서 생성·복제 — 중복 실행 방지, 진행·결과 경로·실패 재시도 표시, 이동·편집 중 늦은 완료의 자동 전환 방지, 만들어진 파일은 '문서 열기'로 다시 접근
- 새 문서 기본 이름은 한국어·영어 설정 반영 · 복제는 원본 바이트를 보존하고 완성된 파일만 등록하며 이름 충돌 시 기존 파일 유지
- 문서 휴지통 이동 — 파일 메뉴에서 경로·복구 방법 확인, 열린 본문을 복구 초안에 먼저 보관, 파일 변경 시 재확인, Finder 휴지통에서 복원
- 라이트/다크 자동(시스템 추종) · 글꼴 크기·읽기 단 폭 설정
- 고아 이미지 정리(assets/에서 참조 없는 파일 검색·삭제)
- 외부 변경 감지 — 수정 중이면 충돌 안내, 아니면 자동 다시 읽기
- 충돌 해결 — 미저장 본문을 버전 기록에 보관한 뒤 다시 읽기, 다른 파일로 저장, 삭제된 파일의 열린 본문 복구 초안 보존, 진행·실패·대상 변경 안내
- 최근 문서, 미저장 확인, 창 상태 복원(위치·크기 포함)
- 닫기 확인 — 대상 파일 목록·저장 진행·실패 재시도, 중복 닫기 방지, 버리기 중 변경 감지와 부분 삭제된 복구 초안 복원, 창 닫기 직전 문서 재확인
- 한국어/영어 UI


## 아키텍처

```text
src/              React 앱(에디터·패널·대화상자·내보내기 UI)
src-tauri/        Tauri 셸(명령·메뉴·감시자·WKWebView PDF·스타일 DB·초안)
crates/
  md-core/        순수 Rust: 마크다운 모델·링크·검색·세션·스냅숏·i18n·트리
  md-export/      내보내기: HTML·PDF·DOCX(OMML/DrawingML)·EPUB·인용·svg2dml
  md-macos/       macOS 플랫폼 계층(휴지통 연동)
```

UI가 파일에 직접 닿지 않는다 — 읽기·쓰기·검색·내보내기는 모두 Rust 코어를 거치며, 코어가
원자적 저장·링크 해석·바이트 수준 보존을 소유한다.

**기술 스택:** React 18 · TypeScript · CodeMirror 6 · Vite · Vitest · KaTeX · mermaid ·
highlight.js · DOMPurify · Tauri 2 · Rust 2021(MSRV 1.89).

## 개발

요구 사항: Rust ≥ 1.89(MSRV), Node 22 LTS, macOS 13.0+.

```sh
npm install
npm run tauri dev      # 개발 실행(포트 1422)
npm run test:unit      # 프런트 단위 테스트(원문 보존 테스트 포함)
cargo test --workspace # Rust 테스트(md-core·md-export)
npm run tauri build    # .app + DMG
```

`npm run tauri build`는 로그인 키체인에 Developer ID Application 인증서가 하나 있으면 그것으로
번들에 서명하고 hardened runtime을 켠다(`scripts/tauri.mjs`; 없으면 ad-hoc 서명으로 빠진다 —
자세한 이유는 스크립트 머리글에).

설계 원칙은 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)을, 구현 상세는
[docs/architecture.md](docs/architecture.md)를 본다.

### 릴리스

릴리스는 `v<version>` 태그를 달고 서명·공증된 DMG를 붙인 GitHub Releases로 게시한다. 전체
체크리스트 — 버전 올림·빌드·공증·`gh release create` — 는 [RELEASE.md](RELEASE.md)에 있다.
태그를 push하면 보호 ref CI job(macOS 번들 빌드 포함,
[.github/workflows/ci.yml](.github/workflows/ci.yml))도 함께 돈다.

## 이름의 의미

IYAGI는 *iyagi* — 이야기 — 로 읽고, 그 안에 **AGI**가 숨어 있다:

```text
IY AGI
   ───
```

AI에게 명령만 내리는 게 아니라 대화하고, 함께 생각하고 실행한다. IYAGI Markdown은 그 가족의
지식 쪽이다:

```text
IYAGI Terminal     → AI 코딩 / 에이전틱 엔지니어링   (출시 — sh2orc/iyagi-term)
IYAGI Markdown     → 지식 / 업무                    (이 저장소)
IYAGI Agent        → 자율 작업
IYAGI Studio       → 에이전트 빌드·오케스트레이션
```

형제 저장소: [iyagi-term](https://github.com/sh2orc/iyagi-term)(AI 코딩 터미널),
[iyagi-layout](https://github.com/sh2orc/iyagi-layout)(레이아웃 엔진).
